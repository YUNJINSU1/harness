# 중고 매물 조사

값을 추정하지 않는다. 매물 목록과 부품 시세를 각각 조회해 **숫자로** 판정한다.

## 1. 조회 경로

**번개장터 — 공개 JSON API.** 인증 불필요, 가장 빠르다.

```bash
curl -s -H 'User-Agent: Mozilla/5.0' \
  'https://api.bunjang.co.kr/api/1/find_v2.json?q=<검색어>&order=date&page=0&n=60&stat_device=w' |
  jq -r '.list[] | "\(.price)\t\(.location // "-")\t\(.name)\thttps://m.bunjang.co.kr/products/\(.pid)"'
```

`location`이 지역 판정에 쓰인다. `order=date`는 최신순, `order=score`는 관련도순.

**중고나라 — 브라우저 필요.** 검색 결과가 JS로 렌더링되므로 `read`로는 내비게이션만 잡힌다.

```javascript
const tab = await browser.open({ name: "shop", url: "https://web.joongna.com/search/<검색어>", wait_until: "networkidle0" });
await new Promise(r => setTimeout(r, 2600));   // 렌더 대기 필수
await tab.evaluate(`[...document.querySelectorAll('a[href*="/product/"]')]
  .filter(a => /\\/product\\/\\d+/.test(a.getAttribute('href') || ''))
  .map(a => ({ t: a.innerText.replace(/\\n+/g, ' | ').trim(), u: a.href }))`);
```

`/product/<숫자>` 필터가 없으면 `/product/form?type=regist`(판매하기 버튼)가 섞인다. 상세 페이지는 로그인 유도로 리다이렉트될 수 있으므로, 목록의 `innerText`에서 가격·등록 경과·무료배송 여부를 먼저 읽는다.

검색어는 여러 개로 나눠 던진다. 모델명(`UM890`), 브랜드(`미니스포럼`), 사양(`미니PC 64GB`), 계열(`SER8`)이 서로 다른 결과를 낸다. 한 검색어로 끝내면 매물을 놓친다.

## 2. 적정가는 부품 시세로 앵커링한다

완제품 가격만 보면 판단할 수 없다. **같은 플랫폼에서 핵심 부품을 따로 검색**해 묶음과 비교한다.

2026-09 실측 예: DDR5 SODIMM 64GB(32GB×2) 중고 **120만원**. 이 시점에 64GB 포함 미니PC 완본체가 140만이면 본체·SSD가 20만인 셈이고, 베어본 45만 + 램 120만 = 165만이 **오히려 비싸다**. AI 수요로 DRAM 공급이 재편돼 부품이 완제품보다 비싸지는 역전이 일어난다.

부품값이 묶음값에 근접하면 그 매물은 싼 게 아니라 **시세가 그렇게 형성된 것**이다. 반대로 부품값을 밑돌면 사기 신호를 먼저 확인한다.

## 3. 사기 판정

**가격 신호.** 시세보다 20~30% 이상 저렴하면 그 자체가 신호다. "이민", "급전" 같은 사유가 붙으면 가중한다.

**판매자 지표** — 상세 페이지에서 확인한다.

| 지표 | 위험 |
| --- | --- |
| 안심결제 후기 0건 | 거래 이력 없음 |
| "첫 안심거래를 기다리고 있어요" | 신규 계정 |
| 계좌등록 미등록 | 정산 준비 안 됨 |
| 마지막 거래일 1년 이상 | 휴면 계정 |

**같은 검색어로 경고글을 찾는다.** 피해자들이 사기 매물을 `사기조심`, `사기글`, `입금받고 연락두절` 같은 제목으로 재등록해 둔다. 모델명으로 검색하면 같이 뜬다. 2026-09 기준 `SER8` 계열에 이런 글이 3건 있었다.

**조회.** 전화번호·계좌번호·카톡 ID를 [더치트](https://thecheat.co.kr)와 경찰청 사이버안전지킴이의 `사이버사기 피해신고 이력 조회`에 넣는다. 후자는 **최근 3개월간 3회 이상** 신고된 건만 노출된다. 둘 다 "이력 없음"이 안전을 뜻하지 않는다 — 새 계좌·새 번호를 쓰는 신규 사기는 걸리지 않는다.

**즉시 중단 조건.** 하나라도 나오면 거래를 끝낸다.

- 판매자가 보낸 결제 링크 (네이버페이·유니크로 위장 피싱)
- 카카오톡·텔레그램 등 외부 채널로 유도
- 예금주가 판매자 개인 이름 (정상 안전결제는 플랫폼 명의)
- "수수료 부족", "입금 확인 안 됨" 재입금 요구
- 판매자와 계좌 명의자 불일치 (삼자 사기)

## 4. 거래 방식

직거래가 최강의 방어다. 실물을 보면 스펙 불일치와 불량을 현장에서 걸러낸다. 지역이 맞지 않으면 **플랫폼 앱 내 공식 안심결제만** 쓴다. 계좌이체를 요구받는 순간 거래를 끝낸다.

대화·게시글·사진을 전부 캡처해 둔다. 판매글은 수정·삭제되면 증거가 사라진다.

기기 종류별 확인 사항은 매물마다 다르지만, 되돌릴 수 없는 항목을 먼저 묻는다. 예: 애플 기기는 활성화 잠금 해제, 미니PC는 정품 어댑터 포함과 램 채널 구성(64GB가 32GB×2인지 1×64인지 — 단일 채널이면 대역폭이 반이다), 확장 포트 실물 사진.

## 5. 보고 형식

가격만 나열하지 않는다. 표에 **가격, 부품값 대비 판정, 판매자 지표, 지역, 등록 경과**를 함께 놓는다. 등록 경과가 길면 안 팔리는 이유(가격·지표·지역)를 추정해 적는다.

재고가 얇은 품목은 그 사실 자체를 보고한다. 전국 1~2건이면 사용자가 하루 한 번 검색해서는 계속 놓친다 — 그때는 감시 자동화를 제안한다.

## 6. 하지 않을 것

- 가격 협상 문구를 먼저 제안하지 않는다. 부품값을 밑도는 매물에 네고를 걸면 판매자가 거래를 접는다.
- 사용자를 대신해 판매자에게 메시지를 보내지 않는다. 문안만 작성해 건넨다.
- 검색 결과의 제목만 보고 사양을 단정하지 않는다. `64GB`가 램인지 저장장치인지, 완본체인지 베어본인지 상세에서 확인한다.
